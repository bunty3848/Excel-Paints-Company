# 🚀 QUICK START GUIDE

## Welcome to Your Excel Paints Website!

Follow these steps to get your website running:

## ⚡ Step 1: Setup (5 minutes)

1. **Open Terminal/Command Prompt** in the website folder
2. **Install dependencies:**
   ```bash
   npm install
   ```
   Wait for installation to complete (2-3 minutes)

## 📸 Step 2: Add Images (2 minutes)

1. **Create images folder:**
   - Already created at: `public/images/`

2. **Add your 4 images:**
   - Copy `Excel_Cem.png` to `public/images/`
   - Copy `Excel_Wall_Putty.png` to `public/images/`
   - Copy `Excel_White_Cement.png` to `public/images/`
   - Copy `Logo.jpg` to `public/images/`

   **Important:** Filenames must match exactly!

## 🎨 Step 3: Run Locally (1 minute)

1. **Start development server:**
   ```bash
   npm run dev
   ```

2. **Open browser:**
   - Go to: `http://localhost:5173`
   - Your website should be running! 🎉

## ✅ Step 4: Test Everything (5 minutes)

- [ ] Click through all 5 pages (Home, About, Products, Gallery, Contact)
- [ ] Test on mobile view (resize browser or use phone)
- [ ] Fill out contact form (check for errors)
- [ ] Click product cards and view details
- [ ] Test gallery lightbox
- [ ] Check all links work

## 🏗️ Step 5: Build for Production (2 minutes)

1. **Create production build:**
   ```bash
   npm run build
   ```

2. **Preview production build:**
   ```bash
   npm run preview
   ```
   
3. **Open:** `http://localhost:4173`

## 🌐 Step 6: Deploy (10-15 minutes)

**Choose ONE option:**

### Option A: Netlify (Easiest)
1. Go to [netlify.com](https://www.netlify.com/)
2. Sign up (free)
3. Drag the `dist` folder onto Netlify
4. Done! Your site is live! 🚀

### Option B: See DEPLOYMENT.md
- Open `DEPLOYMENT.md` for detailed deployment options
- Includes Vercel, GitHub Pages, and traditional hosting

## 🆘 Common Issues

### Images not showing?
- Check: Are images in `public/images/` folder?
- Check: Are filenames correct? (case-sensitive)
- Try: Restart dev server (Ctrl+C then `npm run dev`)

### npm install fails?
- Make sure Node.js is installed (v16+)
- Delete `node_modules` folder
- Run `npm install` again

### Port already in use?
- Use different port: `npm run dev -- --port 3000`
